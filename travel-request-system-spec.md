# Scope of Work

## Project

Design and deliver a travel request and reimbursement system for CARE Kenya. The system will help employees submit requests, managers review them, and authorized administrators oversee records and operations.

## Scope

The work covers:

- Employee account access, including account activation and secure sign-in.
- Employee and manager information import and administration.
- Travel request submission with trip purpose, project details, itinerary, travel mode, accommodation, and passenger information.
- Travel request review, approval or rejection, and resubmission of rejected requests.
- Reimbursement request submission, review, approval or rejection, and resubmission of rejected requests.
- Role-based access for employees, approvers, and superadministrators.
- Request lists with appropriate personal, team, and administrative visibility, filtering, and pagination.
- PDF downloads for travel requests and reimbursement reports.
- In-app and email notifications for relevant request and decision events.
- Audit records for key request and reimbursement actions.

## Deliverables

- A user-facing workflow for travel requests and reimbursements.
- Administrative capabilities for managing employee records and reviewing system-wide activity.
- Notifications, audit history, and downloadable request documents supporting the workflows.
- User and administrator guidance for operating the delivered system.

## Completion Criteria

The work is complete when users can submit and track travel and reimbursement requests; authorized approvers can make and record decisions; rejected requests can be corrected and resubmitted; access is restricted according to user roles; and the agreed notifications, audit records, filtering, and PDF downloads are available.
